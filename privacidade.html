Política de Privacidade

Última atualização: setembro de 2026

Esta página explica como o Painel Bruna — o painel administrativo usado por Bruna Medeiros pra gerenciar seu trabalho como creator, incluindo a conexão com o Instagram — trata os dados acessados através da API do Instagram.

Quem opera este painel

O Painel Bruna é uma ferramenta de uso pessoal, operada e administrada exclusivamente por Bruna Medeiros, para gerenciar sua própria conta profissional do Instagram. Não é um produto oferecido a terceiros nem coleta dados de outras pessoas além do necessário para o funcionamento descrito abaixo.

Quais dados são acessados

Ao conectar a conta do Instagram ao painel, através da API oficial do Instagram (Meta), o painel pode acessar:

  • Informações básicas do perfil profissional (nome de usuário, ID da conta, contagem de seguidores)
  • Métricas e desempenho das publicações (alcance, curtidas, comentários, salvamentos)
  • Comentários feitos em publicações da conta, para identificar palavras-chave configuradas
  • Envio de respostas privadas (mensagens diretas) para pessoas que comentaram uma palavra-chave configurada

Como esses dados são usados

Os dados são usados exclusivamente para:

  • Exibir métricas e desempenho de publicações no painel, para uso interno de Bruna Medeiros
  • Automatizar o envio de uma resposta privada pré-definida quando alguém comenta uma palavra-chave específica em uma publicação (por exemplo, para enviar um link de interesse)
  • Manter um registro simples (nome da conta, se recebeu a resposta, quantas vezes interagiu) para acompanhamento interno

Esses dados não são vendidos, compartilhados ou usados para qualquer finalidade publicitária, e não são repassados a terceiros.

Onde os dados ficam guardados

Os dados são armazenados em um banco de dados privado (Supabase), com acesso restrito à conta de Bruna Medeiros. Os tokens de acesso à API do Instagram são guardados de forma criptografada (Supabase Vault), nunca em texto puro.

Retenção e exclusão

Os dados de conexão com o Instagram são mantidos enquanto a integração estiver ativa. Bruna Medeiros pode desconectar a integração a qualquer momento pelo próprio painel, o que apaga o token de acesso guardado.
